# Prior art

One note per tool or field that overlaps with jachai. Each note answers the same
six questions, so they can be compared side by side.

**Nothing in this directory has been run yet.** Every note is written from
documentation and reading, and each says so in its own "Evidence still missing"
section. No note claims a tool was tested, benchmarked, or verified, because
none has been. Running them is Phase 0 work, and the results belong in
`benchmarks/tools/`, not here.

The purpose of these notes is to make the honest case *against* jachai first: if
an existing tool already covers a bug class, jachai adds nothing there, and the
roadmap's stop condition says so plainly.
